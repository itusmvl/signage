จัดการเพลย์ลิสต์

ตั้งค่าโฟลเดอร์ Google Drive ครั้งเดียวด้านล่าง แล้วแค่อัปโหลดไฟล์ .mp4 ใหม่เข้าโฟลเดอร์นั้น — จอทุกเครื่องจะเล่นให้เองอัตโนมัติ โดยไม่ต้องกลับมาแก้ลิงก์ทุกครั้ง

ข้อจำกัดสำคัญ: หน้านี้เก็บได้เฉพาะ "ลิงก์" วิดีโอ ไม่สามารถอัปโหลดไฟล์วิดีโอจากเครื่องมาฝากไว้ในนี้ได้โดยตรง แนะนำให้ใช้ตัวซิงก์อัตโนมัติจากโฟลเดอร์ Google Drive ด้านล่าง (ตั้งครั้งเดียว ไม่ต้องแก้ลิงก์อีก) หรือถ้าต้องการใช้ที่เก็บไฟล์อื่น (Dropbox, S3/R2/GCS, CDN) ก็เพิ่มลิงก์ตรงแบบ manual ได้ในหัวข้อถัดไป ไฟล์ควรเป็น .mp4 เพื่อให้เล่นได้ในเบราว์เซอร์ทั่วไป

ซิงก์อัตโนมัติจากโฟลเดอร์ Google Drive

ตั้งค่าครั้งเดียว จากนั้น "เครื่องลูก" ทุกจอจะเห็นวิดีโอใหม่เองทันทีที่คุณอัปโหลดไฟล์เพิ่มลงโฟลเดอร์นี้ — ไม่ต้องกลับมาแก้ลิงก์อีกเลย

วิธีตั้งค่า (ทำครั้งเดียว)
  1. สร้างโฟลเดอร์ใน Google Drive ไว้เก็บวิดีโอ signage โดยเฉพาะ แล้วคลิกขวา → แชร์ → เปลี่ยนเป็น "ทุกคนที่มีลิงก์" (ผู้ดู)
  2. เปิดโฟลเดอร์นั้น คัดลอก Folder ID จาก URL เช่น drive.google.com/drive/folders/1AbCxyz... — เอาส่วนหลัง /folders/ มา
  3. ไปที่ Google Cloud Console → เปิดใช้งาน "Google Drive API" ในโปรเจกต์ (สร้างโปรเจกต์ใหม่ได้ฟรี)
  4. ไปที่ APIs & Services → Credentials → Create Credentials → API key คัดลอกคีย์ที่ได้ แล้วกด "Restrict key" จำกัดให้ใช้ได้เฉพาะ Google Drive API เพื่อความปลอดภัย
  5. วาง Folder ID และ API key ด้านล่าง แล้วกดบันทึก
  6. ตั้งแต่นี้ไป แค่ลากไฟล์ .mp4 ใหม่ใส่โฟลเดอร์นั้น (จะตั้งชื่อไฟล์ให้ขึ้นต้นด้วยเลข เช่น 01_intro.mp4, 02_promo.mp4 เพื่อคุมลำดับการเล่น) จอทุกจอจะเล่นไฟล์ใหม่ให้เองภายในไม่กี่วินาที ลบไฟล์ออกจากโฟลเดอร์ก็หายจากคิวเช่นกัน
